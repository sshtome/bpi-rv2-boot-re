# BPI-RV2 — бэкап и восстановление NAND через CH341A + SNANDer

## Суть проблемы

После неудачной прошивки плата BPI-RV2 (SiFlower SF21H8898) циклится с ошибками
`UBI: Bad magic` / `internal ECC error`. При этом FBL («SiFlower SF21H8898 Bootloader»,
первые 128 КБ, адреса 0x0–0x20000) ЖИВ — он тренирует DDR и падает уже на чтении UBI.

**Главное правило: FBL (0x0–0x20000) НЕ трогаем.** Он хранится со своим soft-ECC в OOB,
который обычный программатор не воспроизводит (перезапишешь FBL — получишь полный кирпич).
Восстанавливаем только UBI-область (0x20000+), которая использует on-die ECC самого чипа.

## Что нужно

- CH341A (программатор), подключение к NAND W25N01GV (8-pin SPI).
- SNANDer v1.7.9.x (работает с CH341A; для libusb нужен драйвер WinUSB через Zadig).
- Образ `openwrt-siflower-sf21h8898-bpi-rv2-nand-squashfs-fullflash.img`.

## 1. Бэкап рабочей платы (по желанию)

```bash
# Полный raw-бэкап NAND (данные + OOB, ~138 МБ):
snander -r nand_full_raw.bin -a 0 -l 0x8400000 -d
# -d = отключить on-die ECC (читать page+OOB). Итог: 138 412 032 байта.

# Только FBL с OOB (страховка; 64 страницы × 2112 = 135 168 байт):
snander -r fbl_raw.bin -a 0 -l 0x21000 -d

# Только UBI (данные, 127,875 МБ):
snander -r ubi_data.bin -a 0x20000 -l 0x7fe0000
```

## 2. Подготовка файла прошивки

Из `fullflash.img` вырезаем UBI-часть (всё после первых 128 КБ FBL):

```bash
dd if=openwrt-siflower-sf21h8898-bpi-rv2-nand-squashfs-fullflash.img \
   of=firmware_ubi.bin bs=131072 skip=1
```

Должно получиться **10 616 832 байта** (81 блок × 128 КБ).

## 3. Восстановление кирпича

```bash
snander -i                                              # чип должен определиться W25N01G (0xEF 0xAA)
snander -e -a 0x20000 -l 0x7fe0000                      # стереть UBI (FBL цел)
snander -w firmware_ubi.bin -a 0x20000 -l 0xa20000 -k -v   # записать + верификация
```

Пояснения к флагам:

- `-a 0x20000` — смещение записи (блок 1, FBL не трогаем);
- БЕЗ `-d` — пишем data-only, on-die ECC считает сам чип (это нужно для UBI);
- `-k` — пропускать битые страницы;
- `-v` — верификация после записи;
- `-l 0xa20000` = 10 616 832 (размер firmware_ubi.bin).

## 4. Проверка

Отключить программатор → джампер горизонтально (NAND, дефолт) → подать питание →
UART 115200 8N1. Плата должна дойти до u-boot и загрузить OpenWrt (`root@OpenWrt:/#`).

Проверено: так восстановлена плата с затёртой UBI-областью и целым FBL.
